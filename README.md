# GitHub Insights | تحليل حسابات GitHub

أداة عربية تحلّل أي حساب على GitHub في صفحة واحدة: اللغات، النجوم، النشاط، وأفضل المستودعات، مع مقارنة بين حسابين. تعمل بالكامل في المتصفح بدون سيرفر ولا تسجيل دخول.

## المميزات

- **بطاقة الحساب:** الاسم، النبذة، الموقع، تاريخ الانضمام.
- **أرقام سريعة:** المستودعات، النجوم، التفرّعات، المتابِعون، Gists.
- **ملخص نصي تلقائي** يصف الحساب بجمل عربية.
- **توزيع اللغات** برسم دائري (حسب المستودعات الأصلية).
- **النشاط:** خريطة آخر 91 يوماً، والنشاط حسب اليوم وحسب الساعة، وأنواع الأحداث.
- **أفضل المستودعات** حسب النجوم.
- **مقارنة** بين حسابين مع تمييز الأعلى في كل صف.
- **مشاركة** رابط التحليل (`#u=اسم&v=اسم`) وتحميل البيانات كملف JSON.
- وضع فاتح وداكن، وتصميم متجاوب لكل الشاشات، ودعم RTL.

## كيف يعمل

يستخدم [واجهة GitHub العامة (REST API)](https://docs.github.com/rest) مباشرة من المتصفح:

| الطلب | الاستخدام |
|:--|:--|
| `/users/{user}` | بيانات الحساب |
| `/users/{user}/repos` | المستودعات (حتى 500) |
| `/users/{user}/events/public` | النشاط العام (آخر 90 يوماً، حتى 300 حدث) |

- النتائج تُخزَّن 10 دقائق في `sessionStorage` لتقليل الطلبات.
- الحد المسموح بدون تسجيل دخول **60 طلباً في الساعة** لكل IP، ويظهر العدّاد أسفل الصفحة. كل تحليل يستهلك من 3 إلى 9 طلبات.
- لا يُرسل ولا يُحفظ أي شيء خارج متصفحك.

## التشغيل محلياً

لأن المشروع يستخدم ES Modules، شغّله عبر سيرفر محلي بدل فتح الملف مباشرة:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## هيكل المشروع

```
index.html      الصفحة
style.css       التصميم (وضع فاتح/داكن، متجاوب)
js/api.js       طلبات GitHub، الكاش، معالجة الأخطاء
js/analyze.js   حساب الإحصائيات والملخص
js/charts.js    الرسوم (SVG/HTML بدون مكتبات)
js/app.js       الواجهة والأحداث
```

بدون أي مكتبات خارجية، ولا خطوة بناء.

## الأمان

كل نص قادم من GitHub (الأسماء، النبذة، الأوصاف) يُهرَّب قبل عرضه، والروابط تُفحص قبل استخدامها.
